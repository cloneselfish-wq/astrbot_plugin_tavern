# v0.9.0 数据与发布边界

v0.9.0 是全新发布基线，不是从 v0.8.x 就地升级的兼容补丁。

## 不兼容内容

- v0.8.x 及更早数据库和独立存档
- Schema 1—7 备份
- 世界包协议 v1 或未声明协议版本的世界包
- 旧角色卡草稿、旧冻结契约与旧测试夹具

插件使用新的 `catalog_v090.sqlite3`，不会读取、迁移或覆盖旧数据库。需要保留旧团时，请继续使用对应旧版插件与数据目录。

## v0.9.0 内部备份

同一版本内可以通过管理台导出和导入完整备份。导入前会严格核对：

- 备份格式
- Schema 8
- 当前完整表集合
- ZIP 路径安全与文件校验和
- 合并模式下的稳定 ID 冲突

任何版本不一致都会被明确拒绝，不会尝试猜测转换。

## 世界包更新

运行中的副本继续使用创建时冻结的世界契约。更新世界包只影响以后创建的副本；需要应用新版时，先完成体检，再克隆或新建副本。不得热替换运行中契约。
