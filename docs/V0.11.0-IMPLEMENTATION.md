## 不变量

- `display_no` 只在首次创建或 Schema 9 回填时分配；编辑、排序、归档和恢复均不改变它。
- `sort_order` 只影响管理显示顺序；世界程序引用继续使用数据库 ID 或稳定 `slug`。
- 运行中副本只读取冻结快照；世界编辑不会热替换契约。
- 世界包不执行代码；所有读取、条件、事件阶段和状态操作都经过注册表及白名单。
- dry-run 生成完整计划和凭证但不写状态；正式提交使用 `operation_id` 幂等并与凭证同事务落库。
- 角色资源写入角色运行态，世界变化写入副本世界状态；二者同事务提交或回滚。
- v5 模块没有声明就不启用；插件不提供默认的元素克制、HP/MP、敌我、技能分类、骰制或装备槽语义。
