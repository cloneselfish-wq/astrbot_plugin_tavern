# v0.5.3 Alpha.1 功能与验收基线

## 升级兼容

- 插件版本：`v0.5.3-alpha.1`
- 数据库 Schema：`6`
- 支持从 v0.5.2 及更早数据库原地迁移。
- 不删除 `data/plugin_data/astrbot_plugin_tavern/`；升级前仍建议完整停机备份。
- 保留 v0.5.2 的 Windows SQLite 文件句柄关闭、共享锁重试和原子替换保护。

## 剧情恢复

- 新副本只允许 `/酒馆 开演`；`turn_no > 0` 的旧副本必须使用 `/酒馆 继续`。
- 暂停恢复不会重新生成选项。
- 命名存档保存事件锚点、历史可见起点和完整工作流。
- 读档后保留存档点之前的剧情；存档点之后的旧分支不再进入模型上下文。
- 恢复时重新展示最后一段正式剧情、当前轮次、行动者和活动选项。

## 回合输出契约

- 收到有效选择后立即提示正在生成。
- 生成提示、故事正文和回合选项均通过独立主动发送链投递，不依赖同一事件处理器连续 `yield`。
- 输出顺序固定为“故事推进”消息，然后是“回合秩序＋下一位选项”消息。
- 故事自然段之间由插件加入 `-----------`。
- 每回合故事正文为 100—300 个可见字符。
- 每个选项最多 50 字，括号内容计入限制。
- 每组选项绑定下一位参与者 ID；其他玩家只向模型暴露可观察信息。

## 管理能力

- 倒计时提供总开关和七个分类开关；停用时冻结剩余时间。
- 主持人可强制全部合格出场角色准备。
- 同名存档必须显式确认后才能覆盖。
- 模型 Token 按群、副本、请求类型和供应商记录。
- 群与副本可以分别配置滚动窗口 Token 限额。
- 群 Token 限额位于群会话标题的独立入口；副本详情只管理当前副本限额。
- 玩家私聊确认角色卡后，Bot 会同步在其绑定群提示角色卡已经建立并等待审核。
- 永久归档可只读查看时间线、角色、记忆、账本、时钟和存档。
- 普通快速存档、独立命名存档 ZIP 以及整个已关闭／已归档副本均有受保护删除流程。

## 发布前验证

```bash
python -m unittest discover -s tests -v
python -m py_compile main.py tavern/*.py
node --check pages/console/app.js
python -m json.tool _conf_schema.json
```

发布 ZIP 必须从全新解压目录再次运行同一套测试，并通过 ZIP CRC 检查。
