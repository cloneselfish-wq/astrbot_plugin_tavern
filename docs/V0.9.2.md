# AI 酒馆 v0.9.2 验收基线

- 插件版本：0.9.2
- 数据库：Schema 8，沿用 `catalog_v090.sqlite3`
- 世界协议：v2
- 内置世界：阿尔维恩·灰烬王冠 1.2.0
- 角色卡模板：v3
- 通用模板包：v1.1.0
- NPC 导入模板：v1

## 上下文与速度验收

1. 故事、检定后续写、A—D 选项分别编译上下文，不复用完整世界提示。
2. 每轮叙事不携带 `character_card`、职业预设、出身/身份预设、开场选项或事件池。
3. 常驻 NPC 不在系统层和运行层重复发送；运行层只提供精简投影及必要私密导演信息。
4. 当前行动者与下一行动者相同时，下一行动者使用引用，不重复发送完整角色卡。
5. 选项生成不发送数据库原始参与者行、建卡草稿、绑定码、审核时间或重复角色档案。
6. 选项结构修复不重复原始故事上下文与完整世界规则；通用 JSON 修复也不重复原任务。
7. `safe + check` 由插件确定性规范为安全免检，不触发第二次模型请求。
8. 新副本默认上下文预算为最近 6 回合、6 条记忆、6 名活动 NPC、8 条故事账本。
9. 默认温度为 0.5，单次最大输出为 1400 Tokens；超时时间仍只负责技术保护，不作为提速手段。

## 属性展示验收

1. 世界包与存档继续使用稳定属性 ID，例如 `charisma`。
2. 玩家可见选项、检定回执、存档恢复和紧急替换均显示世界快照中的中文 `label`，例如“魅力”。
3. 选项第一次标准化后保存 `attribute_label`；再次从数据库标准化时不会退回英文 ID。
4. 找不到中文标签时才使用稳定 ID 兜底，不改动第三方世界包与骰制的内部协议。

## 检定消息顺序

```text
🎲【魅力检定】［常规］18 +1 → 19 / DC 9 · 大成功

【酒馆】已收到你的选择，后续内容正在生成中……

📖 【故事推进】
（文字 AI 根据锁定回执续写）
```

机器骰点、风险—DC、结果锁定、重复消息幂等和故事重生成复用原骰点继续遵循 v0.9.1 基线。

## 内置世界与模板

- 阿尔维恩内容版本升级至 1.2.0；建卡、属性与剧情规则不重置，只调整默认上下文预算并补充上下文职责。
- 通用世界包和 NPC 模板包升级至 1.1.0，声明 v0.9.2 兼容性、推荐上下文预算及中文标签规则。
- 已有副本继续使用冻结世界快照，但提示词编译和中文展示修复立即生效；新建副本使用 1.2.0 参数。

## 自动验证

发布包必须通过 Python 编译、JSON/YAML 解析、前端 ES 模块语法检查、内置及通用世界包严格体检、完整单元测试和 ZIP 解压后复验。测试需覆盖上下文裁剪、角色投影、修复提示大小、`safe + check` 确定性修复、中文属性跨保存保留和低延迟默认值。
