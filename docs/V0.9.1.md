# AI 酒馆 v0.9.1 验收基线

- 插件版本：0.9.1
- 数据库：Schema 8，沿用 `catalog_v090.sqlite3`
- 世界协议：v2
- 内置世界：阿尔维恩·灰烬王冠 1.1.0
- 角色卡模板：v3
- 通用模板包：v1.0.0
- NPC 导入模板：v1

## 建卡验收

1. 绑定建卡码后只显示当前字段，不提前发送职业、地区、身份或势力总览。
2. 进入预设字段时自动读取结构化预设；复杂预设分页显示。
3. 当前页序号、稳定 ID、值、名称和别名均可选择；翻页不推进字段。
4. 角色卡保存展示值、稳定 ID 与效果快照。
5. 重复平台消息只消费一次。
6. `/酒馆 上一步`、`/酒馆 修改 <字段>`、`/酒馆 当前步骤` 可用。
7. 修改职业后清理职业基础属性、主属性和副属性，不清理无关背景。
8. 条件字段、互斥字段、空预设、无效引用和循环依赖均经过校验。

## 检定验收

必检选项固定消息顺序：

```text
🎲【魅力检定】［常规］18 +1 → 19 / DC 9 · 大成功

【酒馆】已收到你的选择，后续内容正在生成中……

📖 【故事推进】
（文字 AI 根据锁定回执续写）
```

1. 必检选项不调用文字 AI 决定是否检定或临时填写 DC。
2. 风险通过世界包 `difficulty_policy` 映射 DC。
3. 骰制必须通过运行时注册表取得，未知骰制拒绝执行。
4. 随机数由机器生成，结果在公开前写入回执。
5. 模型失败、超时、恢复或故事重生成不得重新投骰。
6. 文字 AI 只能依据锁定结果续写，最终故事不重复附带骰点。

## 自动验证

发布包必须通过 Python 编译、JSON/YAML 解析、前端 ES 模块语法检查、世界包严格体检、完整单元测试与解压后复验。

通用世界包必须与当前插件版本、世界协议、角色卡模板版本一致并通过同一套严格体检；NPC 模板必须符合当前导入载荷结构。上述版本会同时写入运行时常量和 `templates/template-manifest.json`，任一不一致都视为发布失败。修改世界协议、建卡字段接口、预设向导、检定接口、NPC 导入字段或稳定 ID 规则时，必须在同一变更中更新模板、说明、清单与测试。
