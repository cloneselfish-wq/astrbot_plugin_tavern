# AI 酒馆 v0.9.0 验收基线

- 插件版本：0.9.0
- 数据库：Schema 8
- 世界协议：v2（严格）
- 默认世界：阿尔维恩：灰烬王冠
- 默认游玩计时：全部关闭
- 旧数据迁移：不支持

## 必须通过

1. 全模块编译、JSON 与管理台 JavaScript 语法检查。
2. 新数据库初始化后只播种阿尔维恩，Schema 为 8。
3. 协议 v1、无协议世界与 Schema 7 备份均被拒绝。
4. 新副本倒计时策略全部为关闭，继续/读档不会恢复策略关闭的计时器。
5. 配置提醒后只在截止前指定时间产生一次提醒。
6. 同一平台事件重复投递只消费一次行动。
7. 角色卡候选版本审核前不替换当前版本。
8. 世界包导入→编辑→导出保留未知扩展字段。
9. 管理台版本显示、静态资源缓存参数与发布元数据一致。
10. ZIP 顶层仅包含 `astrbot_plugin_tavern/`，不含缓存、旧安装包或测试产物。
