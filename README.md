# AI 酒馆

> 当前版本：`v0.9.2`  
> AI 主持的多人群聊跑团与互动叙事插件。

AI 酒馆面向 AstrBot 群聊运行。玩家在准备大厅加入副本、私聊建立角色卡，再进入有明确行动权、规则裁定、事务防重与持久存档的多人故事。普通群聊始终旁路，不调用酒馆模型，也不写入酒馆时间线。

## 核心能力

- 多群、多世界、多副本独立运行；同群可保存多条互不串档的故事线。
- A—D 行动回合、机器随机骰制、锁定检定回执、集体投票与优势/劣势。
- 按步骤展示预设的私聊建卡向导、管理员审核、角色卡修订版本、替补与返场流程。
- 世界包协议 v2、导入体检、可视化编辑、冻结契约与克隆迁移评估。
- 回合事务防重、精确急救、保护点回滚、崩溃阶段识别与脱敏诊断。
- 情境帮助、故事回顾、NPC/线索/场景时钟、独立备份与恢复。
- 模块化仓库、服务容器、事件钩子与注册式扩展接口。
- 分用途上下文编译、精简角色/NPC 投影与低成本选项修复，减少重复 Token 和等待时间。

## 安装

1. 在 AstrBot 插件管理中安装本 ZIP，或将 `astrbot_plugin_tavern` 目录放入插件目录。
2. 在插件配置中填写至少一个真实管理员 ID，并按需配置允许群。
3. 选择主要叙事模型；备用模型、图片转述模型与富卡片均可选。
4. 打开管理台完成世界包体检，再在群内使用 `/酒馆 开启`。

`v0.9.2` 沿用 `v0.9.0` 建立的 Schema 8 与世界协议 v2 数据基线；仍不读取 `v0.8.x` 及更早版本的数据库、存档、备份或旧协议世界包。`v0.9.0`、`v0.9.1` 均可直接升级。已有副本继续使用冻结的世界快照，同时立即使用本版精简上下文编译器；新建副本使用本版内置世界参数。

## 管理员快速开始

```text
/酒馆 开启
/酒馆 开启 <副本标识>
/酒馆 开演
/酒馆 暂停
/酒馆 恢复
/酒馆 继续
/酒馆 审核
/酒馆 状态
```

管理台可维护世界与常驻 NPC、建立或检索群副本、管理完整角色卡、调整回合秩序、处理投票与计时器、执行精确急救、查看审计并导出诊断包。

所有游玩倒计时在新副本中默认关闭。建卡码有效期与模型/数据库超时属于技术保护；只有管理员主动启用“即时团”或“慢速群团”等时间预设后，玩家回合、投票、准备和候补计时才会运行。

## 玩家快速开始

```text
/酒馆 加入
私聊：/酒馆 建卡 <验证码>
私聊：/酒馆 当前步骤
私聊：/酒馆 上一步
私聊：/酒馆 修改 <字段名称或稳定key>
/酒馆 准备
jg A
/酒馆 投票 A
/酒馆 回顾
/酒馆 帮助 回合
```

建卡只在进入职业、种族、地区、身份等对应步骤时显示相关预设；复杂预设自动分页，可回复本页序号、名称或稳定 ID，发送“下一页/上一页”翻页。

玩家只能提交自己角色的行动，不得代替其他玩家决定台词、情感或结果。必检选项会先由插件公开机器骰点，再发送“后续内容正在生成中”，文字 AI 只能依据锁定回执续写故事，不能修改骰点、DC 或结果档位。

## 世界包与扩展

世界包使用纯 JSON 协议 v2，只描述世界、角色卡预设、数值、骰制、风险—DC 映射、结果档位、NPC、事件池和时间规则，不执行 Python 或 JavaScript。导入前必须通过体检。

可信 Python 扩展可通过 `tavern.api` 注册骰制、检定解析器、世界校验器、叙事守卫、摘要提供器和后台动作，或监听已提交的生命周期事件。扩展只能调用公共服务接口，不能绕过权限、事务与审计直接写数据库。
