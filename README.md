# AI 酒馆

> 当前版本：`v0.9.0`  
> AI 主持的多人群聊跑团与互动叙事插件。

AI 酒馆面向 AstrBot 群聊运行。玩家在准备大厅加入副本、私聊建立角色卡，再进入有明确行动权、规则裁定、事务防重与持久存档的多人故事。普通群聊始终旁路，不调用酒馆模型，也不写入酒馆时间线。

## 核心能力

- 多群、多世界、多副本独立运行；同群可保存多条互不串档的故事线。
- A—D 行动回合、结构化检定、锁定骰点、集体投票与优势/劣势。
- 私聊建卡、管理员审核、角色卡修订版本、替补与返场流程。
- 世界包协议 v2、导入体检、可视化编辑、冻结契约与克隆迁移评估。
- 回合事务防重、精确急救、保护点回滚、崩溃阶段识别与脱敏诊断。
- 情境帮助、故事回顾、NPC/线索/场景时钟、独立备份与恢复。
- 模块化仓库、服务容器、事件钩子与注册式扩展接口。

## 安装

1. 在 AstrBot 插件管理中安装本 ZIP，或将 `astrbot_plugin_tavern` 目录放入插件目录。
2. 在插件配置中填写至少一个真实管理员 ID，并按需配置允许群。
3. 选择主要叙事模型；备用模型、图片转述模型与富卡片均可选。
4. 打开管理台完成世界包体检，再在群内使用 `/酒馆 开启`。

`v0.9.0` 是全新数据基线，不读取 `v0.8.x` 及更早版本的数据库、存档、备份或旧协议世界包。请勿覆盖旧版数据目录后期待自动迁移。

## 管理员快速开始

```text
/酒馆 开启
/酒馆 开启 <副本标识>
/酒馆 开演
/酒馆 暂停
/酒馆 恢复
/酒馆 继续
/酒馆 审核
/酒馆 状态
```

管理台可维护世界与常驻 NPC、建立或检索群副本、管理完整角色卡、调整回合秩序、处理投票与计时器、执行精确急救、查看审计并导出诊断包。

所有游玩倒计时在新副本中默认关闭。建卡码有效期与模型/数据库超时属于技术保护；只有管理员主动启用“即时团”或“慢速群团”等时间预设后，玩家回合、投票、准备和候补计时才会运行。

## 玩家快速开始

```text
/酒馆 加入
私聊：/酒馆 建卡 <验证码>
/酒馆 准备
jg A
/酒馆 投票 A
/酒馆 回顾
/酒馆 帮助 回合
```

玩家只能提交自己角色的行动，不得代替其他玩家决定台词、情感或结果。关键结果由世界规则、锁定骰点与叙事裁定共同决定。

## 世界包与扩展

世界包使用纯 JSON 协议 v2，只描述世界、角色卡、数值、骰制、危险度、NPC、事件池和时间规则，不执行 Python 或 JavaScript。导入前必须通过体检。

可信 Python 扩展可通过 `tavern.api` 注册骰制、检定解析器、世界校验器、叙事守卫、摘要提供器和后台动作，或监听已提交的生命周期事件。扩展只能调用公共服务接口，不能绕过权限、事务与审计直接写数据库。
